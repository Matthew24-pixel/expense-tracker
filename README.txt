# Expense Tracker — Installment 1

## Required structure

python-course/
└── activities/
    └── module-00/
        └── expense-tracker/

## Run

Open the `expense-tracker` folder in VS Code, open the integrated terminal, and run:

```text
python tracker.py
```

Replace `<Your Full Name>` in `tracker.py` with your full name.

4. Push to `main`.
